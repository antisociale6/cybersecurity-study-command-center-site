# Free Defensive Cybersecurity Portfolio Templates

These twelve blank Markdown worksheets help turn controlled defensive-security
labs into reviewable portfolio evidence. Every template includes an explicit
authorization record, five topic-specific sections, evidence and limitation
fields, and a completion check.

Use them only with owned, synthetic, fictional, or explicitly authorized
systems and information.

1. [Cyber-Risk Baseline for a Synthetic Small Business](cyber-risk-register-template.md) - An evidence-led method for documenting assets, risks, current safeguards, and priority decisions in a controlled cybersecurity study scenario.
2. [Design-Stage Threat Model for a Local Appointment Service](web-service-threat-model-template.md) - A design-stage workflow for mapping assets, actors, data flows, trust boundaries, and reviewable security decisions for a small web service.
3. [Evidence-Led Windows Configuration Drift Assessment](configuration-drift-check-template.md) - A practical method for defining an evidence-based configuration baseline and reviewing change safely in a disposable study environment.
4. [Authentication and Session Control Design Review](authentication-session-review-template.md) - An evidence-led design review for authentication, recovery, session handling, monitoring, and user-safe failure behavior.
5. [Object-Level API Authorization Verification](api-authorization-test-matrix-template.md) - A controlled workflow for reviewing object-level authorization, role boundaries, safe failure behavior, and abuse-resistant API decisions.
6. [Secrets Lifecycle and Local Leak-Prevention Control](secrets-lifecycle-template.md) - A safe study method for mapping how synthetic secrets are created, stored, used, rotated, detected, revoked, and evidenced.
7. [SBOM Quality Review and Dependency Risk Decision](sbom-risk-decision-template.md) - An evidence-led workflow for reviewing a software bill of materials, dependency identity, known risk signals, and documented remediation decisions.
8. [Least-Privilege Container Hardening Assessment](container-hardening-review-template.md) - A controlled container review covering provenance, privileges, filesystem access, configuration, resource boundaries, and evidence-led tradeoffs.
9. [Least-Access Network Segmentation Validation](network-segmentation-test-matrix-template.md) - An evidence-led method for translating approved communication needs into least-access network policy and reviewable validation cases.
10. [Behavior-Based Detection Engineering and Tuning](detection-tuning-evaluation-template.md) - A safe detection-engineering workflow for defining behavior, using synthetic events, testing positive and negative cases, and recording limitations.
11. [Synthetic Incident Response Tabletop and After-Action Review](incident-tabletop-decision-log-template.md) - A structured tabletop method for testing roles, evidence handling, decisions, communications, recovery priorities, and follow-up actions.
12. [Measured Ransomware-Resilience Restore Exercise](recovery-evidence-report-template.md) - A malware-free recovery exercise using disposable copies, integrity evidence, restore criteria, and documented recovery limitations.
